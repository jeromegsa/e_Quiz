# e-Quiz

Application web de quiz interactive, développée en full-stack.

## Stack
- Front-end : Vue.js, TypeScript, Tailwind CSS
- Back-end : Laravel (PHP), API REST
- Tests : PHPUnit

## Installation
### Back-end
cd quizbackend && composer install && php artisan serve
### Front-end
cd quizfrontend && npm install && npm run dev
